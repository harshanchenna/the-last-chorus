# Brief — the founding documents

The original, immutable source documents this project was built from. They are the **"why"** behind
everything in the repo. Read these once for full context, then work from the living docs at the repo
root (which stay current cycle-to-cycle).

- **[`SEED_PROMPT.md`](./SEED_PROMPT.md)** — the project brief & operating manual: vision, the five
  pillars, the world bible, tech stack, architecture requirements, the milestone roadmap (M0–M6+),
  the placeholder-first asset pipeline, and the self-iteration protocol. Section references in the
  living docs (e.g. "seed §8", "seed §6") point here.
- **[`ASSET_SPEC.md`](./ASSET_SPEC.md)** — the full asset production spec (a hand-off sheet for an
  artist / sprite tool / music tool): resolutions, palettes, sprite frames & animation names, audio
  stems, file-naming contract, and production priority.

## How these relate to the root docs

| Brief (here, immutable)        | Root (living, kept current)                                      |

| `SEED_PROMPT.md` — the mandate | `AGENTS.md` — the operating rules distilled for any agent        |

| —                              | `DESIGN.md` · `ARCHITECTURE.md` · `TODO.md` · `ITERATION_LOG.md` |
